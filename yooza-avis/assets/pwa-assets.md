# Assets PWA Yooza

Les fichiers de cette section sont dérivés des logos officiels Yooza fournis le 16 août 2026.

| Fichier | Usage |
|---|---|
| `yooza-logo-anthracite.png` | Logo officiel anthracite, destiné aux surfaces claires. |
| `yooza-logo-jaune.png` | Logo officiel jaune, source du logo de navigation et des icônes. |
| `yooza-logo-sidebar.png` | Mot-symbole jaune isolé sur fond transparent pour la sidebar anthracite. |
| `icons/icon-192.png` | Icône Android/PWA standard. |
| `icons/icon-512.png` | Icône PWA haute définition. |
| `icons/icon-maskable-512.png` | Icône Android maskable avec zone de sécurité renforcée. |
| `icons/apple-touch-icon.png` | Icône dédiée à l’écran d’accueil iOS. |
| `icons/favicon-16.png`, `icons/favicon-32.png` | Favicons navigateur. |

L’icône PWA utilise le **Y officiel jaune** sur fond anthracite `#1E1E1C`. Elle a été vérifiée visuellement afin de garantir la lisibilité sur smartphone.

Le script reproductible `scripts/build_pwa_assets.py` permet de régénérer ces exports depuis le logo jaune officiel.
